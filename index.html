Commandes disponibles

/play [titre]

Recherche et joue une chanson depuis Jamendo avec menu de sélection.

/stop

Arrête la musique et déconnecte le bot du salon vocal.

/queue

Affiche la file d'attente musicale actuelle.

/utilisateur [user]

Affiche les informations détaillées d'un utilisateur.

/salon [channel]

Affiche les informations d'un salon Discord.

/serveur

Affiche les statistiques et infos du serveur.

/clear [nombre]

Supprime un nombre spécifique de messages (permissions requises).

/nombre

Génère un nombre aléatoire entre 1 et 10.

🇫🇷 Politique de confidentialité

Dernière mise à jour : 25 octobre 2025

▼

Bienvenue sur Assistante Barbara. Cette politique de confidentialité explique comment nous collectons, utilisons et protégeons vos données lors de l'utilisation de notre bot Discord.

1. Identité du responsable

Nom du bot : Assistante Barbara
Nature : Application Discord (bot)
Hébergement : Katabump et serveurs locaux (maintenance)

2. Données collectées

Assistante Barbara collecte un minimum absolu de données :
  • Logs de commandes : Informations relatives aux commandes exécutées (horodatage, type de commande) sont temporairement stockées dans les logs système.
  • Suppression automatique : Ces logs sont automatiquement supprimés lors des redémarrages réguliers de l'application.
  • Aucune donnée personnelle persistante : Aucun message, identifiant utilisateur, historique de conversation, préférence musicale ou autre donnée personnelle n'est conservée de manière permanente.

3. Utilisation des APIs tierces

Assistante Barbara utilise les services suivants :

  • Discord API : Pour fonctionner sur Discord. Consultez la politique de confidentialité de Discord.
  • OpenAI API : Pour les fonctionnalités d'intelligence artificielle. Les messages envoyés aux salons configurés sont traités par OpenAI conformément à leur politique de confidentialité.
  • Mistral AI API : Pour les fonctionnalités d'intelligence artificielle. Consultez la politique de confidentialité de Mistral AI.
  • Jamendo API : Pour les fonctionnalités musicales. Consultez la politique de confidentialité de Jamendo.

Important : Les conversations avec l'IA et les recherches musicales sont transmises à ces APIs pour traitement mais ne sont pas stockées par Assistante Barbara elle-même.

4. Finalité du traitement

Les données temporaires collectées (logs de commandes) sont utilisées uniquement pour :

  • Assurer le bon fonctionnement technique du bot
  • Déboguer et corriger d'éventuels problèmes
  • Améliorer les performances

5. Conservation des données

Durée maximale : Les logs sont conservés jusqu'au prochain redémarrage de l'application (généralement quelques jours maximum).

6. Droits des utilisateurs (RGPD)

Conformément au Règlement Général sur la Protection des Données (RGPD), vous disposez des droits suivants :

  • Droit d'accès : Obtenir une copie de vos données
  • Droit de rectification : Corriger des données inexactes
  • Droit à l'effacement : Demander la suppression de vos données
  • Droit d'opposition : Vous opposer au traitement
  • Droit à la limitation : Limiter le traitement

Note : Étant donné que nous ne conservons aucune donnée personnelle de manière permanente, l'exercice de ces droits est généralement sans objet. Néanmoins, vous pouvez nous contacter pour toute question.

7. Sécurité

Nous mettons en œuvre des mesures techniques appropriées pour protéger les données traitées temporairement :

  • Hébergement sécurisé (Katabump)
  • Accès restreint aux logs système
  • Suppression automatique des données temporaires

8. Transfert de données

Les données peuvent être transférées vers :

  • États-Unis : OpenAI, Discord
  • France/Europe : Mistral AI
  • Luxembourg : Jamendo

Ces transferts sont effectués conformément aux clauses contractuelles types de l'UE ou autres mécanismes légaux appropriés.

9. Modifications

Cette politique peut être modifiée occasionnellement. La date de dernière mise à jour sera toujours indiquée en haut du document.
